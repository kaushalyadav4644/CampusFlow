# CampusFlow 🎓

[![JavaScript](https://img.shields.io/badge/Language-JavaScript-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![Status](https://img.shields.io/badge/Status-Active-success.svg)]()

A modern college course registration portal built for seamless student enrollment, course exploration, and credit tracking.

---

## 🚀 Features

* **Course Exploration:** Browse available college courses with detailed descriptions, prerequisites, and credit values.
* **Seamless Enrollment:** Register and drop courses effortlessly with real-time seat tracking.
* **Credit Tracking:** Keep track of total earned credits and semester loads dynamically.
* **Responsive UI:** Clean, intuitive interface optimized for both desktop and mobile views.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
